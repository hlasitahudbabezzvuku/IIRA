# IIRA

IIRA is a high-performance systems **programming language** built by students, featuring a **compiler**, **build system** and a zero-dependency **standard library**.



### Note: We Are in Prototyping Stage

This is a **student-led project** in its very **early stages**. We are currently prototyping the core language features and the self-hosting compiler.

While we are excited to share our progress, please note that IIRA is at this moment **unusable**. We welcome early feedback and discussions, but we recommend against using the language for anything beyond experimentation. If you find a bug or have a suggestion, feel free to open an issue.



### Goal: The Living Laboratory

Most educational languages are "toys" - simplified models built only for demonstration. Most professional languages are "monsters"—complex systems with decades of legacy code that are impossible for a student to navigate.

IIRA aims to be the **middle ground**. We are building a language capable of solving real-world problems, but with a codebase designed to be read, understood, and modified by students. You aren't just learning from a textbook; you are learning by building a tool that actually works.
